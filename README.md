# Consumer Advice API - Console App (`consumer-advice-api-net-console`)

Aplicação Console desenvolvida em C# (.NET) para consumir o endpoint da **Advice Slip JSON API** e exibir um conselho aleatório no terminal.

## 📌 Funcionalidades

- Requisição HTTP assíncrona com `HttpClient`.
- Desserialização de dados JSON com `System.Text.Json`.
- Exibição formatada do conselho obtido diretamente via API.

## 🌐 Endpoint Utilizado

- **URL:** `https://api.adviceslip.com/advice`
